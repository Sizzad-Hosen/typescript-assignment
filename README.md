# TypeScript Assignment

## Assignment Overview

This repository contains solutions to practical TypeScript exercises that demonstrate core language features, type safety, object-oriented programming, and asynchronous programming.

## Completed Work

All programming solutions are included in [`solutions.ts`](./solutions.ts). The exercises cover:

- Optional parameters and default behavior
- Union types and type narrowing
- Readonly tuples and destructuring
- Generic array operations
- Interfaces and array filtering
- Generics with `keyof`
- Classes, inheritance, and access modifiers
- Asynchronous validation with `Promise`
